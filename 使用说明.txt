一、怎么开始
------------------------------------------------------------------------

双击「考公练习追踪看板.html」，用 Chrome 或 Edge 打开。

第一次打开只有一条示例数据（2026-09-19 第29季），是为了让你看清表格长
什么样。点它的「删除」删掉，或者点「编辑」改成你自己的就行。

页面上有六个页签：

  模块一：行测套卷记录   记录列表，增删改查、搜索排序、导入导出 Excel
  模块二：统计分析       各模块的正确率、平均、最高、阶段目标、状态
  模块三：趋势分析       分数 / 击败比 / 各模块正确率 / 用时的趋势图
  模块四：用时分析       实际用时 vs 你的标准用时，达成率、超时排行
  模块五：每日计划       日计划 / 周计划，可设每日或每周重复，勾选完成
  模块六：学习计时       秒表 / 番茄钟，记录每天学了多久，看出时长分布

顶部按钮：
  + 新增一套套卷记录 / 导入 XLSX / 导出 XLSX / 数据备份 / 数据恢复 / 清空记录


------------------------------------------------------------------------
二、数据存在哪（★ 这段最重要，请一定看完）
------------------------------------------------------------------------

数据存在你自己的浏览器里。我们不存任何数据，也看不到你的成绩。

好处是隐私、离线可用；代价是数据只在这台设备的这个浏览器里。
以下情况会导致看不到数据：

  - 换电脑、换手机、换浏览器     → 数据不会跟过去
  - 清理浏览数据（含"Cookie 及其他站点数据"）  → 被清掉
  - 用隐私 / 无痕窗口打开         → 关掉窗口就没了
  - 同一台电脑上多人共用同一个浏览器 → 会互相看到、互相覆盖

请做这两件事：

【1】绑定数据文件夹（推荐，仅 Chrome / Edge）

  「模块一」→「数据存储」卡片 → 点「绑定数据文件夹」
  → 在弹窗里选中一个固定目录（比如新建一个「考公数据」文件夹）

  之后每次改动都会自动写成 JSON 文件存在那个目录里，你可以直接看到、
  复制、放进网盘。

  浏览器重启后可能需要再点一次「恢复访问」重新授权，这是浏览器的安全
  要求，绕不过去。

【2】定期「数据备份」

  点顶部的「数据备份」，会导出一个 JSON 文件（存到浏览器的下载目录）。
  这是最可靠的保险——浏览器数据会丢，只有你手里那份 JSON 不会。

  换设备时，用「数据恢复」选中那个 JSON 就能全部还原。

  备份里包含：套卷记录、目标设置、标准用时、每日计划、循环规则、学习计时
  记录。唯一不跟着走的是「正在进行的那个计时」——恢复后会清掉，避免出现
  一个假装着在跑的计时器。

三、手机上能用吗
------------------------------------------------------------------------

能用，但有一个硬性前提：**必须用"网址"打开**。

  手机请用这个链接：

        https://cuizhiyu712.github.io/kg_viewer/

  这里说的"网址"，就是 http:// 或 https:// 开头的链接。
  为什么手机不能用本地文件？这不是设置问题，是浏览器的安全限制：

    - iPhone 的 Safari 打开本地 HTML 文件时，不允许网页保存数据，
      会完全存不住
    - 安卓的 Chrome 不允许打开本地 HTML 文件
    - 微信 / QQ / 钉钉 内置浏览器打开本地文件根本不会运行

  所以手机上请用链接打开（微信里直接点开即可）。
  如果你手上只有文件、没有链接，那这个工具在手机上就用不了——
  请改在电脑上用（电脑上双击文件即可，不受这些限制，但请用
  Chrome 或 Edge，Safari 同样存不住）。

其他注意事项：

  - iPhone 特别注意：如果连续 7 天没打开过页面，Safari 可能会清掉这个
    页面的本地数据。
    解决办法：把页面「添加到主屏幕」当 App 用（这样不受 7 天限制），
    或者勤点「数据备份」。

  - 手机上「绑定数据文件夹」用不了（iPhone 上的浏览器都不支持；安卓需要
    Chrome 132 以上），所以手机用户更要靠「数据备份」。

  - 手机上打开会是一份全新的空数据，和你电脑上的不是同一份。

四、Excel 导入导出
------------------------------------------------------------------------

导入 XLSX
  只读取 Excel 的第一个 Sheet。请使用「套卷复盘」那种模板
  （纵向结构：总题数 / 正确题数 / 正确率 / 平均正确率 / 用时）。
  日期 + 试卷名重复的记录会弹窗问你是「跳过」还是「覆盖」。

导出 XLSX
  导出「套卷复盘.xlsx」，结构和模板一致，可用 Excel / WPS 直接打开继续编辑。

如果提示「无法识别该 Excel 的 Sheet1 结构」，通常是 Sheet 结构不对，
检查一下模板。

五、每日计划与学习计时（模块五、六）
------------------------------------------------------------------------

【模块五：每日计划】

  「+ 新增计划」里可以建日计划或周计划，每张卡片有：标题、日期、具体
  学习内容、学习时长、是否完成。

  两个好用的地方：

  - 学习内容有两种写法，每个计划自己选：
      文本形式  一段话，可以换行
      清单形式  多条子任务，每条有内容 + 分钟，可以逐条勾。卡片上会显示
                进度条和完成数，学习时长自动汇总（不用自己算）
  - 重复：选「每日重复」或「每周重复」（每周 = 与起始日期同一个星期几），
    还可以填截止日期。系统会自动把实例铺到「今天」和「本周日」中较晚的
    那天，之后每次打开自动补齐，历史不会丢。

  卡片左上角的勾选框就是「是否完成」，点一下即可，不用进编辑页。
  过期的未完成计划会标红提醒。日期已过且没完成，会显示「已过期」。

  想改或想停掉一个循环计划：用「循环计划」区域里的「编辑 / 停止」，
  或者在某一天的卡片上选「编辑 / 删除」，会问你「只改这一次」还是
  「改整个循环」——勾完整条循环、只删某一天，都不会互相影响。

【模块六：学习计时】

  开始计时有两种入口：计划卡片上的「▶ 开始」，或者模块六里自由计时
  （不选计划、自己填标签）。

  计时方式可以切换：
    正计时    从开始一直计到结束
    番茄钟    默认 25 分钟专注 + 5 分钟休息（时长可在「番茄设置」里改），
              每 4 个番茄后长休息 15 分钟。到点会响一声并把浏览器标题闪动
              提示。休息时间不计入学习时长。

  计时中页面右下角会有一个悬浮计时条，切到任何页签都看得见，可以暂停/结束。
  关掉浏览器再打开，计时会接着走（按时间戳算，不是靠页面一直开着）。

  结束后会生成一条学习记录，模块六里可以看到：
    - 今日 / 本周 / 本月学习时长，以及平均每天（只算有记录的天数）
    - 当天的时间线列表（几点到几点、学了什么、多久）
    - 时长分布饼图，可以切换「按科目」或「按计划」看

  计划卡片上会显示「实际」学习时长（由计时记录汇总），可以跟「计划」时长对照。


------------------------------------------------------------------------
六、几个使用上的约定
------------------------------------------------------------------------

  - 正确率不用手填，由「正确题数 ÷ 总题数」自动算。
    你需要填的是：总题数、正确题数、用时。

  - 「平均正确率」可以填「无」（留空即无）。

  - 「标准用时」在「模块四」右上角「编辑标准用时」里改，模块和子模块都能
    改；留空表示不设标准（那一行不参与超时排行）。

  - 新增记录时会自动带出上一套的题数（题量通常固定），但不会沿用上一套的
    平均正确率——那个每次都是单独查的，沿用容易被误当成新数据。

  - 记录里如果出现「原始数据存在不自洽」的黄框提示，说明源表的"合计"和
    "各模块之和"对不上。工具会按原值保留，不会偷偷改你的数据，同时在详情
    里把差异列出来给你看。


------------------------------------------------------------------------
七、常见问题
------------------------------------------------------------------------

Q：打开是一片空白？
A：用 Chrome 或 Edge 打开。文件较大（约 2MB，内含图表库），第一次打开
   稍等一下。

Q：我只有文件、没有网址，能在手机上用吗？
A：不能。手机浏览器不允许打开本地 HTML 文件时保存数据（iPhone 的 Safari
   会直接报错，安卓 Chrome 会拒绝打开）。手机上必须用网址。请在电脑上
   用，或者找给你文件的人要一个链接。

Q：能换台电脑继续用吗？
A：可以。旧电脑「数据备份」导出 JSON → 新电脑「数据恢复」导入。

Q：能让手机和电脑数据自动同步吗？
A：当前版本不能——数据不经过服务器，这是隐私换来的代价。跨设备需要手动
   备份 / 恢复。

Q：数据会不会被上传到网上？
A：不会。这个文件没有任何联网请求，成绩只存在你自己浏览器里。

Q：能几个人一起用吗？
A：可以，但每个人要各自复制一份文件、各自记录。数据不会互通。
