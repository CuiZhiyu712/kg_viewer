# 考公练习追踪看板

纯前端、本地存储、单文件运行的「考公练习追踪看板」。

## 怎么用

双击 **`考公练习追踪看板.html`** 即可。**不需要联网**——ECharts 和 SheetJS 已内联进文件
（约 2.1 MB，gzip 后约 688 KB），零外部请求，实测离线/内网都能跑。

数据默认存在浏览器 `localStorage`（键名 `kaogong_dashboard`），刷新不丢失，
但换浏览器 / 清浏览数据会丢。**建议绑定数据文件夹**（见下）让数据固定落盘。

要部署到远程给别人用，看 **[DEPLOY.md](DEPLOY.md)**（GitHub Pages 逐步操作 +
上线前必须定下来的三件事）。

## 数据存哪

两层：

| 存储 | 角色 | 特性 |
| --- | --- | --- |
| 浏览器 localStorage | 工作副本 | 即时、离线可用、所有浏览器一致；但被锁在浏览器 profile 里 |
| `./data/kaogong_data.json` | 落盘真身 | 可读 JSON，能直接看 / 进 git / 用别的工具处理 |

在「模块一 → 数据存储」卡片点 **「绑定数据文件夹」**，在弹窗里选中项目下的 `data` 文件夹，
之后每次新增 / 编辑 / 删除 / 改目标设置都会自动写入 `data/kaogong_data.json`。

**为什么要手动点一下**：浏览器在 `file://` 下没有文件系统权限——`fetch`/`XHR` 读同目录文件
会被拦截，OPFS 还会抛 `SecurityError`。唯一正规通道是 File System Access API，而它按设计
必须由用户手势授权。所以本地页面**不可能**做到"打开就自动读写同目录文件"，这一步绕不过去。

局限：

- 仅 **Chrome / Edge** 支持；其它浏览器该卡片显示为不可用，功能退回到 localStorage，不受影响。
- 浏览器出于隐私不暴露完整路径，界面只能显示文件夹名（所以你选了别的文件夹时会提醒）。
- 浏览器重启后授权可能失效，卡片会变成「已绑定，但需要重新授权」，点「恢复访问」再确认一次即可。
- 每次启动会比对文件与本地内容：一致就静默通过；**不一致则弹窗让你决定以哪边为准，绝不静默覆盖**。

## 主表：子模块正确率小窗

表头「言语理解」「判断推理」可点击：列右侧展开小窗，把每套卷的子模块正确率按行排开，
**行与主表数据行逐行对齐**（不标日期，靠对齐读行）。着色沿用该列模块的阶段目标 /
黄色下限，与主表同一套绿 / 黄 / 红规则。小窗复用主表的单元格规格，并在
打开 / 窗口缩放 / 切回 Tab 时把每行高度照抄主表对应行——主表「操作」列的按钮会把数据行
撑高几像素，不照抄就会逐行错位。筛选、排序、增删改后小窗跟随刷新；再点一次表头收起。

## 标准用时与「模块四：用时分析」

「模块四：用时分析」是独立 Tab，把实际用时和你的计划对起来看。

**标准用途完全可改**：点该 Tab 右上角「编辑标准用时」，模块级和子模块级都能改，
留空表示不设标准（该行不参与排行、状态显示「未设标准」）。默认值来自你给的计划：

| 模块 | 政治理论 | 常识 | 言语理解 | 数量 | 判断推理 | 资料分析 |
| --- | --- | --- | --- | --- | --- | --- |
| 计划（分钟） | 10 | 5 | 30 | 10 | 33 | 25 |

判断推理的子模块标准：图形推理 10 / 定义判断 10 / 类比推理 3 / 逻辑判断 10。
**「一拖五」不单列，其用时计入逻辑判断**——这样导出的 Excel 仍是原来的列结构
（O图形 P定义 Q类比 R逻辑判断 S总计），不破坏你的 Sheet1。

页面内容：

- **总用时达成率**：最近一次总用时 ÷ 标准合计。种子数据是 176 / 113 = 155.8%，超时 63 分钟。
- **超时排行**：按「最近一次 − 标准」降序，只列超时的模块；没有超时就改列富余最多的。
- **各模块用时对比**：模块行 + 子模块行（缩进），列为 标准 / 最近一次 / 历史平均 / 差值 / 最大 / 最小 / 状态。
  状态：超时（红）、富余（蓝）、达标（绿）、无数据、未设标准。
- **实际用时趋势**：切换 [总用时] 或任一模块，图上画出实际折线 + 红色虚线标准线。

模块标准用时与其子模块之和不一致时（比如模块 30 但子模块加起来 35），不会静默改数，
页面下方会给出提示——和「合计 76 ≠ 模块之和 81」的处理方式一致。

## 手机 / 平板

已适配，用 Chrome 设备模拟实测过 5 档尺寸（iPhone SE 375、iPhone 14 390、
iPad 竖屏 768、iPad 横屏 1024、小笔记本 1366），验证项含：无页面级横向溢出、
吸顶元素不遮挡、不长期占屏超过 25%、点击区 ≥40px、图表真实渲染、弹窗放得下。

| 场景 | 表现 |
| --- | --- |
| 手机（≤900px） | 页头与 Tab 随页面滚走（不在小屏上钉住四分之一屏幕）；工具栏按钮换行满宽；表单两列排布；表格内部横向滚动 |
| 平板（901–1200px） | 页头单行显示、保持吸顶；Tab 吸顶紧贴页头下沿 |
| 桌面（≥1201px） | 完整多列表格 |

两个已知的取舍：

- **主表 13 列在手机上要横向拖动**（iPhone SE 上约 700px）。信息密度换来的，
  没做「卡片式」移动布局——如果你在手机上看得多，可以让我做一个。
- **「绑定数据文件夹」在移动端要看浏览器**（依据 MDN 兼容表）：

  | 浏览器 | 目录授权 |
  | --- | --- |
  | Chrome / Edge 桌面版 | ✅ |
  | Chrome Android **132+**（2025-01 起） | ✅ |
  | Chrome Android 131 及更早 | ❌ |
  | iOS Safari（及 iOS 上所有浏览器，都是 WebKit） | ❌ |
  | Firefox（含 Android） | ❌ |

  不支持时页面会显示「当前浏览器不支持目录授权」，**其余功能全部照常**。
  我无法在真机验证 Android 的写入行为（只有桌面版 Chrome 我实测过），
  如果你要给安卓用户用，建议让他们先试一次。

⚠️ **iOS Safari 有 7 天限制**（Apple ITP，已查证）：site 若连续 **7 天没有任何用户交互**
（点击/输入），Safari 会删除该站点的**脚本存储，localStorage 和 IndexedDB 都在内**
（`navigator.storage.persist()` 拦不住）。
**豁免方式：把页面「添加到主屏幕」以 PWA 方式使用**，安装后的 Web App 不受此限制。
所以 iPhone 用户两条建议：定期「数据备份」，或添加到主屏幕。

改完源码后重新构建：

```bash
python build.py     # 生成 考公练习追踪看板.html 和 docs/index.html
python pack.py      # 打包成给别人用的 zip（分享版/）
```

**只有一个版本**：本地双击、飞书 H5、GitHub Pages 用的都是同一个产物。
（原先是「保守原版 + overlay 叠加出飞书版」两变体；因为飞书版本就是原版超集，
已合并成一条构建路径，避免改了一边忘了另一边。）

`pack.py` 一次产出两个包：

```
考公练习追踪看板-使用者版-<日期>.zip     ← 微信直接发给使用者（2 个文件，0.7 MB）
└─ 考公练习追踪看板/
   ├─ 考公练习追踪看板.html   双击即用，含一条示例数据
   └─ 使用说明.txt            纯文本，记事本可读（带 UTF-8 BOM 防乱码）

考公练习追踪看板-分享版-<日期>.zip       ← 给要改代码的人（1.5 MB）
└─ 考公练习追踪看板-分享版/
   ├─ 考公练习追踪看板.html
   ├─ 使用说明.txt
   └─ 源码/                   src/ vendor/ build.py pack.py devtest/ feishu/ README.md DEPLOY.md
```

两个包里的产物 HTML **逐字节相同**（`test-share.js` 会断言这一点，防止分叉）。
都会排除 `node_modules`、测试截图、`data/*.json` 和 `*.xlsx`（私人数据绝不进包）。

> 使用者版说明用 `.txt` 而不是 `.md`：`.md` 在 Windows 记事本里会显示成一堆 `#` 和 `|`，
> 对不懂技术的接收者不友好。

`vendor/` 下的两个库文件缺失时，build.py 会跳过内联，页面自动回退到 CDN 加载
（逻辑在 `src/index.html` 的 `KGLoadLibs` 里，带三个备用 CDN）。内联后的内容被
`<!-- VENDOR-LIB-BEGIN -->` / `<!-- VENDOR-LIB-END -->` 包住，测试脚本据此剥离它们——
jsdom 没有 canvas，跑不了真的 ECharts，需要注入受控替身。

## 数据来源约束

**只使用 `套卷复盘137788287964941447.1e985b7db4385be(2).xlsx` 的第一个 Sheet（粉笔模考）。**
其余 Sheet（花生套卷 / 超格套卷 / 国考真题）不读取、不作为分类。

业务模型里只有一种「套卷」，没有「套卷类型」这一概念。

### Sheet1 结构

前两行是模块标题，之后每套卷占 **5 行一个数据块**（块数动态识别，不写死）：

| 行标签（F 列） | 含义 |
| --- | --- |
| 总题数 | 各模块题量 |
| 正确题数 | 各模块正确数；日期/试卷/分数/平均分/击败比 也写在这一行 |
| 正确率 | 由「正确题数 ÷ 总题数」自动计算，网页不手填 |
| 平均正确率 | 用户填写，允许「无」 |
| 用时 | 各模块用时 |

列位：`A`日期 `B`试卷 `C`分数 `D`平均分 `E`击败比 `F`行标签 `G`合计
`H`政治理论 `I`常识 `J`逻辑填空 `K`片段阅读 `L`语句表达 `M`言语理解总计
`N`数量 `O`图形推理 `P`定义判断 `Q`类比推理 `R`逻辑判断 `S`判断推理总计 `T`资料分析

## 需要你知道的几个决定

1. **首次打开会自带一条初始数据**（2026-09-19 第29季），来自你 Excel 的第一套卷。
   浏览器在 `file://` 下无法读取同目录的 xlsx，所以把它内置了，保证「双击就能看到原有套卷」。
   再导入同一个 xlsx 时会被「日期 + 试卷」去重拦下。
2. **源表自身有不一致，网页按原值保留，并在详情页明确标出**，不静默改写：
   - 合计 76 ≠ 六大模块正确数之和 81（而分数 58.5 ≈ 76/130，说明「合计」是原始真值）
   - 言语理解总计用时 38 ≠ 三个子模块之和 37
   导出 Excel 时会原样还原这些值；但若在网页里**编辑并保存**该记录，整套卷汇总会按
   六大模块自动重算（保存前表单里会提示具体会变成多少）。
3. **「平均正确率」是每模块的输入字段**（按你的更正实现），允许填「无」。
   与「统计分析」里由历史自动算出的「平均正确率」是两个不同的东西，
   统计表里分成两列：「平均正确率」（按历史算）与「记录平均正确率」（该套卷记录里填的值）。
4. **「总题数」保留为输入项**：正确率要由它算出来。新增时自动带出上一套的题数，通常不用改。
   刻意**不**沿用上一套的「平均正确率」，避免旧值被误当成新数据存下来。
5. **日期不用 SheetJS 的 `cellDates`**：它会把 2026-09-19 变成 `2026-09-18T15:59:17Z`，
   本地取值后整体差一天。改为直接读 Excel 序列号并做 UTC 整数运算。
6. 源表脏数据会被归一化：`50%%` → 50、`100%%` → 100、`无`/`None` → 空。
   导出时对导入的记录逐格还原（保留 `50%%`、`无` 原样）。


`test-browser.js` 的截图输出在 `devtest/shots/`。

> `test-parse.js` 与 `test-roundtrip.js` 需要根目录存在原始表格
> `套卷复盘137788287964941447.1e985b7db4385be(2).xlsx`。
> 该文件被 `.gitignore` 排除（不进公开仓库），克隆后请把它放回根目录再跑这两个测试；
> 其余测试不依赖它。

已验证：

- `file://` 下 localStorage、IndexedDB 均可用；无控制台报错。
- 导出的 xlsx 为真日期单元格（`yyyy/m/d`）与百分比格式（`0.00%`），合并单元格左上角有值。
- 真实鼠标点击「绑定数据文件夹」能成功呼出系统选择框（无头环境随即自动关闭，
  表现为「已取消选择」，不是安全拦截），说明 `file://` 下的授权通道是通的。
- 数据文件夹的序列化 / 签名比对 / 自动落盘 / 覆盖 / 解绑逻辑（jsdom + 内存假目录）。
- **零外部请求**：CDP 抓网络，加载过程只有 2 个请求、无任何 http(s) 外链，可离线运行。
- **子模块小窗逐行对齐**：真实 Chrome 里注入 3 条临时记录量像素——小窗表头/每个数据行
  与主表对应行的 top 差值为 0，左边缘钉在被点表头的右边缘。
- **安全上下文差异**：`http://127.0.0.1` 有目录授权能力；`http://192.168.x.x` 下
  `showDirectoryPicker` 直接不存在，卡片准确提示"不是 https"，其余功能不受影响。

**未验证**（需要有 GUI 的真人操作一次）：

- 真正选中 `data` 文件夹后的写入效果——无头环境无法完成选择框交互。
- 目录句柄持久化：`file://` 下句柄写入 IndexedDB 后，**浏览器重启**能否免授权直接恢复。
  这一条只能靠真人试一次。
- Microsoft Excel 本体的实际打开效果（仅用 SheetJS 回读校验结构与格式）。
